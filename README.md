Eden Health was a primary and virtual care company that delivered app-based medical care, behavioral health, and care navigation to employers and their employees, integrating with health systems and insurers (backed by Insight Partners). It was surfaced as an Insight Partners portfolio company and added to the API Evangelist network for enrichment. Its public marketing site is no longer reachable over TLS, but its primary backend service — the "Grdn" (Guardian) API at api.edenhealth.com — still serves a Swagger 2.0 description covering patients, appointments, membership, documents, care teams, and clinician tooling.

**Areas:** Company · Healthcare · Primary Care · Virtual Care · Telehealth · Digital Health · Patients · Appointments

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Eden Health: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
